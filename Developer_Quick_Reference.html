Make it configurable from admin panel! ──────────────────────────────────────────────────────────────────────────── 2️⃣ NITROGEN FERTILIZER (Scope 1 + Scope 3) ──────────────────────────────────────────── Input: fertilizer_kg (float), fertilizer_type (string: "Urea", etc.) Step A: Get nitrogen content nitrogen_fraction = { "Urea": 0.467, "Ammonium_Nitrate": 0.35, "Ammonium_Sulphate": 0.21, "DAP": 0.18, "NPK_15_15_15": 0.15 } n_content_kg = fertilizer_kg * nitrogen_fraction Step B: Calculate emissions ef_direct = 4.16 (kg CO₂e per kg N) [IPCC 2019 Ch11] ef_indirect = 0.30 (kg CO₂e per kg N) [IPCC 2019] emissions_direct_kg = n_content_kg * ef_direct emissions_indirect_kg = n_content_kg * ef_indirect emissions_total_kg = emissions_direct_kg + emissions_indirect_kg Example: 100 kg Urea Step A: n_content = 100 * 0.467 = 46.7 kg N Step B: direct = 46.7 * 4.16 = 194.27 kg CO₂e (Scope 1) indirect = 46.7 * 0.30 = 14.01 kg CO₂e (Scope 3) total = 208.28 kg CO₂e = 0.208 tonnes CO₂e Database Setup: table 1: emission_factors factor_name = "n2o_direct" → 4.16 factor_name = "n2o_indirect" → 0.30 source_standard = "IPCC 2019 Chapter 11" table 2: fertilizer_composition fertilizer_type = "Urea" → n_percent = 46.7 fertilizer_type = "Ammonium_Nitrate" → n_percent = 35 [and others...] ⚠️ MAKE BOTH CONFIGURABLE IN ADMIN PANEL! ──────────────────────────────────────────────────────────────────────────── 3️⃣ ELECTRICITY (Scope 2 - Indirect Emissions) ──────────────────────────────────────────── Input: kwh_consumption (float), source_country (string, default: "Egypt") Formula: emissions_kg = kwh_consumption * 0.60 Output: kg CO₂e Source: IEA 2024 + Egypt Ministry of Electricity Example: 13428 kWh/year → 8056.8 kg CO₂e → 8.06 tonnes CO₂e Database Setup: table: emission_factors field: factor_name = "electricity_egypt" field: factor_value = 0.60 field: unit = "kg CO₂e/kWh" field: source_standard = "IEA + Egypt MoE 2024" Grid Factors (add more countries later): Egypt: 0.60 Saudi_Arabia: 0.65 UAE: 0.55 Sudan: 0.45 ──────────────────────────────────────────────────────────────────────────── 4️⃣ SOIL CARBON CHANGE (Scope 1 - Land Management) ──────────────────────────────────────────── Input: area_hectares (float), practice_type (enum) Mapping: "Conventional_Tillage" → +0.3 "Conservation_Agriculture" → -0.5 "No_Till_With_Cover_Crop" → -1.0 "Agroforestry" → -2.0 Formula: emissions_tonnes = area_hectares * factor Example: 100 ha × (-0.5) = -50 tonnes CO₂e/year (Negative = carbon sequestration/removal, which is GOOD!)
